# Changelog

All notable changes are documented here. This project follows Semantic
Versioning while DSH compatibility remains pinned to explicitly verified
developer-preview releases.

## 0.1.0 - 2026-08-21

### Added

- DSH bundle and Cordis lifecycle entry point.
- Eight typed VPN operations tools.
- Allowlisted SSH targets with strict host-key and public-key-only policy.
- Short-lived configuration- and baseline-bound plans.
- Atomic WireGuard and VLESS Reality configuration, backup, verification, and rollback.
- Non-echoing client export to local mode-`0600` files.
- Test, coverage, CI, package, security, and release evidence gates.
